## BAGIAN 1 — SISTEM KOMPUTER
### 1. Apa itu Sistem Komputer?
Sistem komputer adalah sekumpulan komponen yang bekerja sama untuk menerima data, mengolah data, menyimpan data, dan menghasilkan informasi.
Sederhananya:
Input → Process → Output → Storage
Contoh ketika kita mengetik nama di komputer:
Keyboard → CPU → Monitor
- Keyboard = memasukkan data
- CPU = mengolah data
- Monitor = menampilkan hasil
### Analogi sederhana
Bayangkan restoran.
Restoran | Komputer
Pelanggan memberikan pesanan | Input
Koki mengolah makanan | Process
Makanan diberikan ke pelanggan | Output
Resep/bahan disimpan | Storage
Jadi komputer sebenarnya bekerja dengan konsep yang cukup sederhana:
Masukkan sesuatu → komputer mengolah → keluar hasil.
## 2. Komponen Utama Sistem Komputer
### Secara umum terdapat 3 komponen utama:
### A. Hardware
Hardware adalah perangkat keras komputer yang dapat kita lihat dan sentuh.
Contoh:
- Keyboard
- Mouse
- Monitor
- CPU
- RAM
- SSD
- Printer
- Speaker
### B. Software
Software adalah perangkat lunak berupa program yang menjalankan fungsi tertentu.
Contoh:
- Windows
- Linux
- Android
- Microsoft Word
- Google Chrome
- Visual Studio Code
- Game
- Aplikasi editing
Software tidak bisa kita pegang secara fisik seperti hardware.
### C. Brainware
Brainware adalah manusia yang menggunakan atau mengoperasikan komputer.
Contoh:
- Programmer
- Guru
- Siswa
- Administrator
- Teknisi
- Designer
Jadi:
Hardware + Software + Brainware = Sistem komputer yang dapat digunakan.
### 3. Jenis-Jenis Perangkat Komputer
Perangkat komputer dapat dikelompokkan berdasarkan fungsinya.
### A. Input Device
Perangkat untuk memasukkan data ke komputer.
Contoh:
- Keyboard
- Mouse
- Scanner
- Microphone
- Webcam
- Touchscreen
Contoh:
Kita mengetik Halo menggunakan keyboard.
Keyboard berfungsi sebagai input device.
### B. Processing Device
Perangkat yang digunakan untuk mengolah data.
Contoh utama:
CPU
CPU atau Central Processing Unit sering disebut sebagai "otak" komputer.
CPU menjalankan instruksi dari program.
Contohnya ketika kita menjalankan kalkulator:
10 + 5
CPU memproses operasi tersebut sehingga menghasilkan:
15
### C. Output Device
Perangkat yang digunakan untuk menampilkan hasil pengolahan data.
Contoh:
- Monitor
- Speaker
- Printer
- Projector
Misalnya:
Keyboard → Komputer → Monitor
Input     Process    Output
### D. Storage Device
Perangkat yang digunakan untuk menyimpan data.
Contoh:
- HDD
- SSD
- Flashdisk
- Memory card
Contoh:
Kita menyimpan file:
Tugas_RPL.docx
File tersebut disimpan pada media penyimpanan.
### 4. Apa Itu RAM?
RAM (Random Access Memory) adalah tempat penyimpanan sementara yang digunakan komputer ketika menjalankan program.
Contohnya kita membuka:
- Chrome
- VS Code
- Spotify
- WhatsApp
Program-program tersebut membutuhkan RAM.
Analogi:
SSD = lemari untuk menyimpan barang.
RAM = meja tempat kita bekerja.
Semakin luas meja, semakin banyak barang yang bisa kita kerjakan bersamaan.
Tetapi RAM bersifat sementara. Ketika komputer dimatikan, data yang berada di RAM tidak dipertahankan seperti data yang tersimpan di SSD.
### 5. Apa Itu SSD/HDD?
SSD dan HDD merupakan perangkat penyimpanan.
Digunakan untuk menyimpan:
- Sistem operasi
- Aplikasi
- Foto
- Video
- Dokumen
- Game
- File proyek
### Perbedaan sederhananya:
SSD | HDD
Lebih cepat | Lebih lambat
Tidak menggunakan piringan mekanis | Menggunakan piringan mekanis
Lebih tahan terhadap guncangan | Lebih sensitif
Umumnya lebih mahal per kapasitas | Umumnya lebih murah per kapasitas
## BAGIAN 2 — SISTEM OPERASI

Operating System (OS) atau sistem operasi adalah software utama yang mengatur perangkat keras dan menyediakan lingkungan agar aplikasi dapat berjalan.
Contoh:
- Windows

- Android
- iOS
Tanpa sistem operasi, penggunaan komputer akan menjadi jauh lebih sulit karena aplikasi membutuhkan sistem yang mengatur hardware dan berbagai layanan dasar.

## BAGIAN 3 — ALGORITMA
### 1. Apa Itu Algoritma?
Algoritma adalah langkah-langkah logis dan sistematis untuk menyelesaikan suatu masalah.
Tidak harus langsung berhubungan dengan komputer.
Contoh:
Algoritma membuat mie instan
1. Siapkan mie
2. Masak air
3. Masukkan mie
4. Tunggu sampai matang
5. Masukkan bumbu
6. Aduk
7. Sajikan
Itulah algoritma.
Jadi algoritma sebenarnya sudah kita gunakan dalam kehidupan sehari-hari.
### 2. Analogi Algoritma
Bayangkan kamu ingin pergi ke sekolah.
Tujuan:
Rumah → Sekolah
Kamu membutuhkan langkah:
1. Bangun
2. Mandi
3. Memakai seragam
4. Sarapan
5. Mengambil tas
6. Keluar rumah
7. Pergi ke sekolah
Urutan tersebut penting.
Kalau:
1. Pergi ke sekolah
2. Mandi
3. Bangun
jelas tidak masuk akal.
Itulah pentingnya algoritma.
### 3. Algoritma dalam Pemrograman
Dalam pemrograman, kita memberikan instruksi kepada komputer.
Komputer tidak berpikir seperti manusia.
Kita harus memberikan instruksi yang:
- jelas
- logis
- terurut
- tidak ambigu
Misalnya kita ingin membuat program menentukan apakah seseorang boleh masuk.
Algoritmanya:
1. Masukkan umur
2. Periksa umur
3. Jika umur >= 17
      tampilkan "Boleh masuk"
4. Jika tidak
      tampilkan "Belum boleh"
Kemudian algoritma tersebut dapat diterjemahkan ke bahasa pemrograman.
### 4. Kenapa Algoritma Penting?
Algoritma membantu programmer:
Memahami masalah
Sebelum coding, kita harus tahu:
"Sebenarnya masalah apa yang ingin diselesaikan?"
Membuat program lebih terstruktur
Program tidak dibuat secara asal.
Mengurangi kesalahan
Kita dapat mengetahui langkah mana yang salah.
Mempermudah coding
Algoritma bisa dianggap sebagai rencana sebelum menulis kode.
### 5. Algoritma ≠ Bahasa Pemrograman
Ini penting untuk siswa baru.
Algoritma adalah cara/langkah penyelesaian masalah.
Bahasa pemrograman adalah bahasa yang digunakan untuk menerjemahkan instruksi tersebut agar dapat dijalankan komputer.
Contoh:
Algoritma
1. Masukkan angka
2. Tambahkan angka dengan 10
3. Tampilkan hasil
Kemudian algoritma tersebut dapat dibuat menggunakan Python:
angka = 5
hasil = angka + 10
print(hasil)
Hasil:
15

Bahasa pemrograman adalah bahasa yang digunakan manusia untuk memberikan instruksi kepada komputer melalui program.

"Tolong hitungkan 10 + 20."

Contoh bahasa pemrograman:

- Java
- JavaScript
- C

17. Bahasa Pemrograman vs HTML
Ini sangat penting untuk RPL.

"HTML adalah bahasa pemrograman."

BAGIAN 5 — HTML DASAR
18. Apa Itu HTML?
HTML (HyperText Markup Language) adalah bahasa markup yang digunakan untuk membuat struktur halaman web.
Contohnya kita ingin membuat website sekolah.
Kita membutuhkan:
Judul
Paragraf
Gambar
Link
Tabel
Daftar
Form
HTML membantu menyusun semuanya.
19. Analogi HTML
Bayangkan kita membangun rumah.
HTML       = struktur rumah
CSS        = tampilan/dekorasi
JavaScript = perilaku/interaksi
Contohnya:
HTML
↓
Membuat tombol
CSS
↓
Membuat tombol menjadi bagus
JavaScript
↓
Membuat tombol melakukan sesuatu ketika diklik
Jadi dalam web development:
HTML = struktur
CSS = tampilan
JavaScript = interaksi
20. Struktur Dasar HTML
Dokumen HTML memiliki struktur dasar seperti:
<!DOCTYPE html>
<html>
<head>
    <title>Website Saya</title>
</head>
<body>
    <h1>Halo Dunia!</h1>
    <p>Ini website pertama saya.</p>
</body>
</html>
Mari kita bahas satu per satu.
21. <!DOCTYPE html>
<!DOCTYPE html>
Memberi tahu browser bahwa dokumen menggunakan standar HTML modern.
22. <html>
<html>
...
</html>
Merupakan elemen utama yang membungkus dokumen HTML.
23. <head>
<head>
    <title>Website Saya</title>
</head>
Berisi informasi/metadata mengenai halaman.
Contohnya:
<title>Website Saya</title>
Judul tersebut biasanya muncul pada tab browser.
24. <body>
<body>
    ...
</body>
Berisi konten utama yang ditampilkan pada halaman web.
Misalnya:
<h1>Halo</h1>
<p>Selamat datang.</p>
25. HTML Tag
HTML menggunakan tag.
Contoh:
<h1>Halo</h1>
Strukturnya:
<h1>     = tag pembuka
Halo     = isi
</h1>    = tag penutup
Contoh lain:
<p>Belajar HTML</p>

27. Heading
HTML memiliki heading:
<h1>Judul Utama</h1>
<h2>Subjudul</h2>
<h3>Subjudul Kecil</h3>

Semakin besar angka, biasanya semakin rendah tingkat heading-nya.
28. Paragraf
Gunakan:
<p>Ini adalah paragraf pertama.</p>
<p>Ini adalah paragraf kedua.</p>
Browser akan menampilkan dua paragraf.
29. Link
Untuk membuat link:
<a href="https://example.com">Kunjungi Website</a>
href merupakan attribute yang menentukan tujuan link.
30. Gambar
Contoh:
<img src="gambar.jpg" alt="Foto pemandangan">
src:
Menentukan lokasi gambar.
alt:
Memberikan teks alternatif yang menjelaskan gambar.
31. Apa Itu Attribute?
Attribute memberikan informasi tambahan pada sebuah HTML element.
Contoh:
<a href="https://example.com">
    Website
</a>
Di sini:
<a>       = tag
href      = attribute
URL       = nilai attribute
Website   = isi
Bentuk sederhananya:
<tag attribute="value">
Misalnya:
<input type="text" placeholder="Nama">
Terdapat beberapa attribute:
input
 ├── type
 └── placeholder
32. Kenapa HTML Harus Diberi Spasi?
Ini bagian yang bagus untuk ditekankan kepada siswa.
Perhatikan:
<img src="foto.jpg" alt="Foto saya">
Ada spasi antara:
img
↓
src
↓
alt
Spasi tersebut membantu browser membedakan nama tag dengan attribute.
Secara konsep:
<tag attribute="value">
Misalnya:
<input type="text" placeholder="Nama">
Terdapat beberapa attribute:
input
 ├── type
 └── placeholder
Kalau ditulis sembarangan:
<input type="text"placeholder="Nama">
Pada HTML tertentu browser masih dapat melakukan parsing karena HTML cukup toleran terhadap whitespace, tetapi jangan biasakan menulis seperti itu.
Biasakan:
<input type="text" placeholder="Nama">
Karena:
Kode yang rapi lebih mudah dibaca, dipahami, diperbaiki, dan dikembangkan.
33. Spasi dan Indentasi
Perhatikan:
Kurang rapi
<html>
<head>
<title>Website</title>
</head>
<body>
<h1>Halo</h1>
<p>Selamat datang</p>
</body>
</html>

<html>
    <head>
        <title>Website</title>
    </head>
    <body>
        <h1>Halo</h1>
        <p>Selamat datang</p>
    </body>

Keduanya dapat diproses browser.
Namun kode kedua jauh lebih mudah dibaca.
Inilah yang disebut indentation/indentasi.
34. Kenapa Programmer Harus Menulis Kode dengan Rapi?

Jadi:
Kode yang rapi bukan sekadar masalah penampilan, tetapi membantu manusia memahami kode.

BAGIAN 6 — LATIHAN LOGIKA PEMROGRAMAN
Sebelum siswa banyak melakukan coding, latihan logika sangat penting.
Tidak perlu langsung menggunakan bahasa pemrograman.
Tujuannya adalah membiasakan siswa:
berpikir → menganalisis → menentukan langkah → mencari solusi.
Soal 1 — Urutan
Kamu ingin membuat teh.
Urutkan langkah berikut:
A. Memasukkan gula
B. Merebus air
C. Memasukkan teh ke gelas
D. Menuangkan air panas
E. Mengaduk teh
Jawaban:
1. B
2. C
3. A
4. D
5. E
Soal 2 — Kondisi
Sebuah program menentukan apakah siswa lulus.
Syarat:
Nilai minimal = 75
Jika:
Nilai = 80
Apa outputnya?
Jawaban:
Lulus
Soal 3
Jika:
Nilai = 60
dan syarat lulus:
Nilai >= 75
Apa outputnya?
Jawaban:
Tidak lulus
Soal 4 — Logika
Sebuah pintu hanya dapat dibuka jika:
Kartu = benar
DAN
PIN = benar
Jika:
Kartu = benar
PIN = salah
Apakah pintu terbuka?
Jawaban:
Tidak.
Karena menggunakan operator AND, keduanya harus benar.
Soal 5 — AND
Kapan kondisi berikut bernilai TRUE?
A AND B
A | B | Hasil
TRUE | TRUE | ?
TRUE | FALSE | ?
FALSE | TRUE | ?
FALSE | FALSE | ?
Jawaban:
A | B | Hasil
TRUE | TRUE | TRUE
TRUE | FALSE | FALSE
FALSE | TRUE | FALSE
FALSE | FALSE | FALSE
Soal 6 — OR
Sebuah sistem memberikan akses jika:
Memiliki kartu
ATAU
Memiliki PIN
Jika:
Kartu = salah
PIN = benar
Apakah mendapat akses?
Jawaban:
Ya.
Karena menggunakan OR, salah satu kondisi benar sudah cukup.
Soal 7 — Perulangan
Bayangkan kamu diminta:
"Cetak kata Halo sebanyak 5 kali."
Tanpa menulis satu per satu, konsep apa yang cocok?
Jawaban:
Perulangan/loop.
Soal 8 — Analisis Masalah
Sebuah vending machine menjual minuman seharga Rp5.000.
Seseorang memasukkan:
Rp10.000
Berapa uang kembalian?
Jawaban:
10.000 - 5.000 = 5.000
Kembalian:
Rp5.000
Soal 9 — Algoritma
Buat algoritma untuk:
Menentukan apakah sebuah angka adalah angka genap atau ganjil.
Petunjuk:
Bilangan genap dapat dibagi 2 tanpa sisa.
Contoh:
10 ÷ 2 = 5
Tidak ada sisa → genap.
Contoh algoritma:
1. Masukkan angka
2. Bagi angka dengan 2
3. Periksa sisa pembagian
4. Jika sisa = 0
      tampilkan "Genap"
5. Jika tidak
      tampilkan "Ganjil"
Soal 10 — Tantangan Logika
Sebuah program memiliki aturan:
Jika umur >= 17
dan memiliki kartu identitas
maka tampilkan "Boleh masuk"
Andi:
Umur = 18
Kartu identitas = ada
Apakah Andi boleh masuk?
Jawaban: Ya.
Budi:
Umur = 18
Kartu identitas = tidak ada
Boleh masuk?
Jawaban: Tidak.
